# GUI Улучшения для InfernaMusic

## Что было изменено:

### 1. Кнопки Previous/Next Track
**До:** Простые эмодзи ⏮ и ⏭
**После:** Полноценные круглые кнопки с иконками

- Размер кнопок: 24x24 пикселей
- Круглая форма с радиусом 12 пикселей
- Полупрозрачный фон (0x26FFFFFF) с подсветкой при наведении (0x40FFFFFF)
- Кастомные иконки вместо эмодзи:
  - `iconPrevious()` - вертикальная полоска + треугольник влево
  - `iconNext()` - треугольник вправо + вертикальная полоска

### 2. Кнопка Play/Pause
**Изменения:**
- Размер: 26x26 пикселей (оптимальный для главной кнопки)
- Улучшено центрирование иконки play
- Улучшено центрирование иконки pause (две полоски по 2px ширины)

### 3. Улучшенное расположение элементов
Обновлены координаты в Layout record:
- `playX()`: cx - 29 (центральная кнопка)
- `playY()`: footY + 6
- `previousX()`: cx - 62 (слева от play)
- `nextX()`: cx + 38 (справа от play)
- `stopX()`: cx + 66 (после кнопки next)
- `stopY()`: footY + 10

Порядок кнопок: **Previous → Play/Pause → Next → Stop**

### 4. Обновленная обработка кликов
- Кнопки Previous/Next: hitbox 22x22
- Кнопка Play/Pause: hitbox 26x26
- Кнопка Stop: hitbox 18x18
- Все кнопки правильно центрированы

