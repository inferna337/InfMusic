# GUI Улучшения для InfernaMusic

## Что было изменено:

### 1. Кнопки Previous/Next Track
**До:** Простые эмодзи ⏮ и ⏭
**После:** Полноценные круглые кнопки с иконками

- Размер кнопок: 24x24 пикселей
- Круглая форма с радиусом 12 пикселей
- Полупрозрачный фон (0x26FFFFFF) с подсветкой при наведении (0x40FFFFFF)
- Кастомные иконки вместо эмодзи:
  - `iconPrevious()` - вертикальная полоска + треугольник влево
  - `iconNext()` - треугольник вправо + вертикальная полоска

### 2. Кнопка Play/Pause
**Изменения:**
- Увеличен размер с 26x26 до 32x32 пикселей
- Улучшено центрирование иконки play (добавлен сдвиг +1 по X)
- Улучшено центрирование иконки pause (более точное позиционирование баров)

### 3. Улучшенное расположение элементов
Обновлены координаты в Layout record:
- `playX()`: cx - 36 (было cx - 30)
- `playY()`: footY + 3 (было footY + 6)
- `previousX()`: cx - 70 (было cx - 64)
- `nextX()`: cx + 46 (было cx + 38)
- `stopX()`: cx + 8 (было cx + 4)

### 4. Обновленная обработка кликов
- Кнопки Previous/Next теперь имеют правильные hitbox'ы (24x24)
- Кнопка Play/Pause обновлена до 32x32
- Все кнопки правильно центрированы

## Технические детали:

### Новые функции:
```java
iconNext(DrawContext g, int cx, int cy, int h, int color)
// Рисует иконку "следующий трек" (треугольник + полоса)

iconPrevious(DrawContext g, int cx, int cy, int h, int color)
// Рисует иконку "предыдущий трек" (полоса + треугольник)
```
