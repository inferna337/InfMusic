Метод центрирования текста в прямоугольнике:

    int centerX(String text, int containerX, int containerWidth) {
        int textWidth = textRenderer.getWidth(text);
        return containerX + (containerWidth - textWidth) / 2;
    }

    int centerY(int containerY, int containerHeight, int textHeight) {
        return containerY + (containerHeight - textHeight) / 2;
    }

  ✓ Footer controls (вся группа кнопок)
  ✓ Track list play buttons (▶/⏸)
  ✓ Track list like buttons (♡/♥)
  ✓ Track list close buttons (×)
